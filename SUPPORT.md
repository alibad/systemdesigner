# Getting Support

Need help with SystemDesigner? Here's the fastest way to get answers, by situation.

## 📚 Learning the material

If you're using the app to learn system design, start at
**[systemdesigner.net](https://systemdesigner.net)** — most concepts link to
prerequisites and related lessons, so you can always find the next step.

## 💬 Questions & ideas → GitHub Discussions

For "how do I…?", "is this the right approach?", architecture debates, or sharing
what you built:

➡️ **[GitHub Discussions](https://github.com/alibad/systemdesigner/discussions)**

This is the best place for open-ended conversation — it's searchable, and answers
help the next person too.

## 🐞 Bugs & 📝 content fixes → GitHub Issues

- Found a bug, a broken page, or a typo? Open a
  [new issue](https://github.com/alibad/systemdesigner/issues/new/choose) and pick
  the matching template.
- Spotted something wrong or unclear **in a lesson**? Every lesson page has
  **"Edit this page on GitHub"** and **"Suggest an improvement"** links at the
  bottom — the fastest way to propose a fix. See
  [docs/CONTENT_GUIDE.md](./docs/CONTENT_GUIDE.md).
- You can also use the in-app **feedback widget** (the button in the corner of the
  app) to report a problem with a screenshot, without leaving the page.

## 🛠️ Running or contributing to the project

- Setting it up locally? See [docs/DEVELOPMENT.md](./docs/DEVELOPMENT.md).
- Want to contribute code or content? See [CONTRIBUTING.md](./CONTRIBUTING.md) and
  [docs/CONTENT_GUIDE.md](./docs/CONTENT_GUIDE.md).
- Understanding how it all fits together? See
  [docs/ARCHITECTURE.md](./docs/ARCHITECTURE.md).

## 📣 Community mailing list

For announcements and broader discussion, the community list is
**system-designer@googlegroups.com**.

## 🔒 Security issues

Please **do not** use public channels for security reports. Follow the private
process in [SECURITY.md](./SECURITY.md).
