# ML Curriculum Expansion Plan

## Current State Analysis
- ✅ **Existing**: Data pipelines, feature engineering, model training/serving, MLOps monitoring, A/B testing
- ❌ **Missing**: LLM fundamentals, RLHF, advanced RAG, model evaluation, AI agents, production challenges

## Proposed New ML Systems Lessons

### Phase 1: LLM & Modern AI Fundamentals
1. **`/ml-systems/llm-fundamentals`**
   - Transformer architecture deep dive
   - Pre-training vs fine-tuning
   - Context windows and attention mechanisms
   - Key model families (GPT, Claude, Gemini, etc.)

2. **`/ml-systems/model-alignment`**
   - RLHF process and implementation
   - Constitutional AI approaches
   - Human feedback collection and reward modeling
   - Policy optimization techniques

3. **`/ml-systems/model-evaluation`**
   - Capability evaluations (MMLU, HumanEval, etc.)
   - Safety evaluations and red teaming
   - Benchmark design and interpretation
   - Automated evaluation frameworks

### Phase 2: Production AI Systems
4. **`/ml-systems/advanced-rag`**
   - Advanced retrieval strategies
   - Hybrid search implementations
   - RAG evaluation and optimization
   - Multi-modal RAG systems

5. **`/ml-systems/ai-agents`**
   - Agent frameworks and architectures
   - Tool use and function calling
   - Memory systems and planning
   - Multi-agent coordination

6. **`/ml-systems/production-optimization`**
   - Latency optimization techniques
   - Cost management strategies
   - Model quantization and compression
   - Caching and batching strategies

### Phase 3: Enterprise & Safety
7. **`/ml-systems/ai-safety`**
   - Prompt injection and jailbreaks
   - Data leakage prevention
   - Bias detection and mitigation
   - Alignment and robustness

8. **`/ml-systems/enterprise-ai`**
   - Data governance and privacy
   - Compliance requirements
   - Model governance and versioning
   - Enterprise deployment patterns

## Integration with Existing Content
- Cross-reference with GenAI section where topics overlap
- Link to technology pages for specific tools/frameworks
- Update existing lessons to reference new advanced topics
- Create learning paths that connect fundamental to advanced concepts

- Complete coverage of modern ML/AI landscape
- Clear progression from fundamentals to advanced topics
- Strong connection between theory and practical implementation
